# * DCMM 专家级审计红线与质量标准 (V2.2 专家沉淀版)

## 一、 绝对红线

以下内容若不满足，直接判定为 **“不通过”**

### 1. 数据战略

- **发文要求**：必须有正式发文证据（文号、发布日期、企业公章），有些特殊情况也可以用全员邮件代替。
- **去模板化**：描述必须具体，反映企业所在行业特征（如精密制造、五金、能源等）。纯模板化内容视为缺位。
- **独立性**：不能仅提供数字化转型战略，要有独立的数据治理战略文件，或**至少要**包含独立的数据战略章节。

### 2. 数据治理

- **行政级别要求**：对于大型企业，顶层管理办法必须是**“公司级/院级（红头文件）**”。仅由“信息部/科技部”等二级部门发文的，视为管理权威性不足，定性为“重大整改”。
- **概念防混淆**：严禁使用“数据管理文件管理办法”（即文控管理）来充当“数据管理办法”。否则可以定性为基本概念不清，一票否决。

### 3. 数据治理活动证据（全局多域）

- **甲方需要系统截图**：必须有数据质量、数据标准、元数据管理的系统截图，完全没有的判定为不通过。
- **实证可信度**：系统截图内容不合理(如数据质量大量不合格、或少量几个数据质量、数据检核规则、没有或很少数据质量检核记录)、大量占位符、或明显是软件产品demo的，视为“未真实运行”，判定为不通过。

### 4. 高等级要求

- **四级** 在满足三级要求之上，必须要有量化评价体系以及工具、过程、效果证据，以及数据类行业标准的参与。
- **五级** 在满足四级要求之上，必须有**主导**数据类国家标准(GB)或行业标准(行标)的制定。
  - **权威性硬伤**：五级企业若提供的“主导标准”仅为“团体标准/协会标准”，或本人仅为“参与人”而非“主要起草人（前三位）”，视为不满足硬性要求。

### 4. 乙方

- **最优先（合同纯度）：** 合同必须是企业级数据治理相关，不能是纯粹的系统集成、系统运维、或单一业务应用开发。
- **实证多样性**：三个或三个以上合同来自同一个客户的框架协议只保留一个。必须提供来自不同行业或不同客户主体的、涵盖咨询/治理/资产化等全流程的合同。
- **辅助能力域：**和同等级甲方要求一致，四级和五级乙方，需要满足甲方三级和四级的所有要求。

## 二、 专家经验项 （重大质疑）

以下涉及红线的领域或其他领域的内容，应判定为 **“重大整改或补充证据”**，但不作为直接否决企业的硬性结论。

### 1. 数据战略

* 数据战略描述要具体，能反映企业特征，否则就是没有真做，对dcmm理解不到位，
* 不能拿数字化战略当数据战略，可以是数字化战略的一部分，但必须独立成章
* 数据战略证据要有目录，有重点内容
* 数据战略发布需要有证据，日期不能太近，一般而言三级不能少于一年，四级和五级不能少于两年
* **连续性**：规划周期必须覆盖评估年度。例如：2023规划已结束，新规划2025才发布，导致**“2024断档”**，视为重大合规缺陷

### 2. 数据治理

* 数据治理组织架构明确，要足够有特征，对业务部门、IT部门和数据部门的关系和参与说的清楚，要有组织架构图，不能是放之四海皆准的标准图
* 数据管理制度顶层文件（数据管理办法等）仅有一个标准化模板化的发文，看不出企业特点，也没有相关有价值的描述的，截图和描述看不出数据管理的范畴、职责分配、工作内容等的，至少要做重大整改，做出解释，现场质疑说不清的也是不合格。
* 数据治理组织设立的发文时间要足够，一般而言三级不能少于一年，四级和五级不能少于两年
* 要明确数据认责、职权范围和管理目的相关的描述，过程活动，否则要质疑只有数据治理制度，但可能是一纸空文

### 3. 数据架构模型

- **数据模型**：至少要有企业级数据概念模型图。
- **专业度**：将“业务处理流程图”误认为数据模型（ERD）反映了专业度严重缺失，需定性为“重大整改”。
- **穿透核验**：严禁将“数据字典/物理表清单”冒充“逻辑模型”。逻辑模型必须体现业务实体间的关联关系。

### 4. 数据质量

- 需要看到系统截图，足够清晰，能看出是企业专属，而不是网上找的产品demo
- **跨部门证据**：仅使用 MES/ERP 系统的数据架构、质量、标准等截图不行，需要有跨业务域的闭环管理的系统证据。

### 5. 数据安全

* 检查是否有请外部机构做的数据审计，尤其是四级，虽然不是红线，如果没有也需要质疑

### 6. 高等级要求

- **量化深度**：四级及以上必须体现 **“过程量化 (Process Metric)”**。如果只有“数据准确率”或“业务收益指标”这类结果性指标，而没有体现对管理活动本身监控的量化（如：战略实施偏差、治理投入效能），视为四级实证不足。
- **行业标杆**：五级还要看是否有足够的证据显示行业影响力。
- **标准有效性**：**“征求意见稿”** 需要现场质疑

### 7. 乙方企业

- **重点能力域：**其中的提到的项目需要有对应合同支撑，没有的需要整改
